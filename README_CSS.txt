CSS SPIDER-MAN SMOOTH & RESPONSIVE

1. Letakkan folder project di C:\\xampp\\htdocs\\
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka melalui http://localhost/NAMA_FOLDER/
4. Jangan membuka file PHP dengan file://.
5. Semua halaman memanggil ./data.css?v=spiderman2026 dan ./laporan.css?v=spiderman2026 agar CSS terbaru tidak tertahan cache browser.
6. Jika browser masih menampilkan tampilan lama, tekan Ctrl+F5 atau hapus cache.
7. data.css dan laporan.css berada di folder yang sama dengan file PHP.
